# pneumonia-detection-transfer-learning
Transfer learning-based pneumonia detection from chest X-ray images using VGG16/ResNet50 and TensorFlow.
In this project, I developed a deep learning model to detect pneumonia from chest X-ray images using transfer learning techniques. A pre-trained CNN architecture (VGG16 / ResNet50) was adapted to perform binary classification between normal and pneumonia-infected lungs.

The project was implemented in Google Colab using TensorFlow and Keras. The dataset was organized and balanced to reduce class imbalance, and multiple training strategies were explored. In addition to a baseline approach, data augmentation techniques were applied to improve generalization performance.

The model was evaluated using accuracy, AUC, precision, and recall metrics. Performance was further analyzed through confusion matrix visualization and ROC curve analysis. Training stability and optimization were enhanced using techniques such as EarlyStopping and learning rate reduction.

This project demonstrates my practical experience in applying transfer learning to medical image analysis and developing AI solutions for real-world healthcare problems.
